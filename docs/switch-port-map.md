# Managed Switch Port Mapping

Example port assignments for the lab switch.

| Port | Device | Purpose |
|---|---|---|
| 1 | LAB_ROUTER | Router uplink |
| 2 | LAB_SERVER | Proxmox host |
| 3 | LAB_SERVICE | Service host |
| 4 | LAB_ADMIN | Admin workstation |
| 5 | LAB_ATTACK | Security testing system |

This table demonstrates typical documentation used to track network connections.
