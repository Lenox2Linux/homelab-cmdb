# Documentation Sanitization Notice

All infrastructure documentation in this repository uses sanitized information.

For security and privacy reasons the following items are intentionally replaced with placeholders:

* Internal IP addresses
* Hostnames
* Domain names
* Authentication credentials
* VPN information
* Public access endpoints

Example placeholders used:

|Placeholder|Meaning|
|-|-|
|LAB\_ROUTER|internal router|
|LAB\_SWITCH|managed switch|
|LAB\_SERVER|server host|
|LAB\_VM|virtual machine|
|LAB\_NET|internal network|

This approach mirrors how engineers share architecture publicly without exposing sensitive information.
