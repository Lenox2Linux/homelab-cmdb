# Monitoring Relationships

This diagram describes how monitoring systems observe infrastructure components.

## Monitoring Flow

Security monitoring tools observe activity across multiple systems.

| Monitoring Tool | Target System | Purpose |
|---|---|---|
| SIEM | Virtual Machines | Security event monitoring |
| Network Analysis | Lab Network | Traffic analysis |
| Service Monitoring | Infrastructure services | Availability checks |

Monitoring documentation is commonly used by SOC teams to understand visibility coverage.
