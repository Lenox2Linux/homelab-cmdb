# Homelab CMDB

This repository contains configuration management and IT asset documentation for a personal cybersecurity home lab.

## Purpose
The goal of this repository is to document infrastructure in an enterprise-style format, including:

- Physical hardware assets
- Virtual machines
- Containers and services
- Network topology
- Access methods
- Service dependencies
- Change tracking

## Technologies in the Lab

- Proxmox
- Ubuntu Server
- Docker
- Wazuh
- Nextcloud
- Portainer
- Uptime Kuma
- Tailscale

## Documentation Goals

- Maintain clear records of infrastructure
- Support troubleshooting and lab scaling
- Practice enterprise-style asset management
- Build portfolio-ready technical documentation
## Why This Project Exists

This repository was created to practice enterprise-style infrastructure documentation using a personal cybersecurity home lab.

The goal of this project is to simulate documentation practices used by IT operations, infrastructure, and security teams such as:

- Configuration Management Databases (CMDB)
- Asset inventory tracking
- Network topology documentation
- Service dependency mapping
- Change tracking

This project also serves as a bridge between academic learning and hands-on experience.

Concepts from the following coursework and certifications are applied here:

- CompTIA A+
- CompTIA Network+
- Linux system administration
- Virtualization and infrastructure management
- Security monitoring concepts used in SOC environments

The documentation in this repository intentionally uses sanitized or placeholder information rather than real network addresses, credentials, or sensitive infrastructure details.

The focus of this project is to demonstrate the ability to:

- document infrastructure clearly
- maintain asset records
- track system relationships
- communicate technical environments effectively

These are skills commonly required for roles such as:

- IT Support Specialist
- System Administrator
- Network Administrator
- Security Operations Center (SOC) Analyst
